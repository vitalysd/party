# Пати для Windows

Установщик: https://31-172-67-27.sslip.io/updates/1.1.2/pati_1.1.2_x64-setup.exe.

Начиная с 1.1.0 кнопка обновлений находится внизу левого столбца рядом с приглашением друга. Она также доступна на экране входа. Нажмите «Проверить обновления», затем «Обновить и перезапустить». Пока идёт голосовой разговор, установка недоступна. Сохранённая авторизация и настройки остаются на месте.

Версии до 1.1.0 нужно один раз обновить вручную. Проверка выполняется только по нажатию кнопки; установка сама по себе не начинается.

## Выпуск обновлений

Из корня проекта:

```powershell
./frontend/scripts/build-windows.ps1 -Version 1.1.3 -Notes 'Описание изменений'
```

Скрипт обновляет версии package.json/Cargo.toml/tauri.conf.json, собирает подписанный установщик и создаёт `artifacts/releases/1.1.3/latest.json`. Номер версии каждого выпуска должен увеличиваться. Папку выпуска нужно загрузить на сервер (например, `/root/pati-release-1.1.3`), затем выполнить:

```sh
python3 /opt/pati/deploy/publish-update.py /root/pati-release-1.1.3
```

Публикация сначала размещает файлы версии, затем атомарно заменяет `/opt/pati/updates/latest.json`. Уже опубликованные версии не перезаписываются. Caddy обслуживает `/updates/` по HTTPS.

Ключ подписи: `.build-tools/signing/pati.key`, публичный ключ — рядом с расширением `.pub` и в конфигурации приложения. Закрытый ключ исключён из Git и ограничен ACL текущего пользователя; на сервер он не передаётся. Сохраните его резервную копию в защищённом хранилище: для следующих выпусков требуется именно этот ключ. Подпись обновлений Tauri не заменяет сертификат Authenticode для Windows.

Приложение подключается к https://31-172-67-27.sslip.io. Используйте тот же аккаунт, что и в браузере. Для подключения сеть должна пропускать TCP 443, а для голоса также порты LiveKit.

Закрытие окна оставляет приложение в трее и сохраняет разговор. Левый клик на значке возвращает окно. Через правый клик доступны «Открыть пати» и «Выйти из приложения». Полный выход прекращает соединение и уведомления. Повторный запуск открывает существующий экземпляр.

Уведомления Windows о новых сообщениях и входящих звонках появляются, когда окно не в фокусе. Нажатие возвращает окно и открывает переписку. В настройках профиля доступны выключение и проверка уведомлений. На Windows корректная регистрация имени приложения для уведомлений требует установки через установщик; portable exe предназначен прежде всего для диагностики. Режим Windows «Не беспокоить» может скрывать уведомления.

Это первая сборка без сертификата подписи кода. Проверка микрофона, захвата экрана и уведомлений в установленной версии с реальным аккаунтом обязательна перед широким распространением.

## Сборка

Требуются Node.js, Rust MSVC, Microsoft C++ Build Tools и WebView2. Из каталога `frontend`:

```powershell
npm ci --legacy-peer-deps
npm run tauri build
```

`--legacy-peer-deps` нужен из-за существующего peer-ограничения emoji-mart для React 19. Cargo.lock и package-lock.json фиксируют версии зависимостей.

Локально установленный инструмент Rust находится в `.build-tools` и исключён из Git. Чтобы использовать его в текущем PowerShell из корня проекта:

```powershell
$env:RUSTUP_HOME = Join-Path $PWD '.build-tools/rustup'
$env:CARGO_HOME = Join-Path $PWD '.build-tools/cargo'
$env:PATH = "$env:CARGO_HOME/bin;$env:PATH"
cd frontend
npm run tauri build
```
